## II. Source Read

The target page does not exist. The V&V strategy is carried by Section 3.1 of System Validation, which states verbatim: "the efficiency of system realization is gained by optimizing the three strategies together to form what is often called the verification and validation strategy." This optimization defines and performs the minimum number of V&V actions while detecting maximum errors and achieving confidence in the system. Validation is "a transverse activity to every life cycle stage" running parallel to system definition and realization. Coordination occurs with project managers (schedule, resources), designers (issue/trouble reports), and configuration managers (baselines, versions). Cross-references include System Verification, System Realization, System Transition, System Operation. The V&V strategy itself is therefore composite: a planning artifact that joins three strategies (verification, validation, integration) into a single optimization.
